# 工业设备智能运维助手

面向制造车间设备运维场景的 RAG 知识问答界面 Demo，适合在 4:3 工位屏上演示。

## 运行

直接用浏览器打开“工业设备智能运维助手.html”，无需安装依赖或启动服务。

## Demo 内容

- 智能问答：通过快捷问题查看故障排查和操作规范回答。
- 证据与引用：查看引用文档、页码、相关度和检索链路。
- 设备档案：查看设备基本信息、运行状态与维护检查要点。
- 知识库：按设备手册、操作规程、故障案例筛选并搜索示例文档。
- 处置记录：查看问答记录；确认生成工单后会显示工单和处置进度。

## 说明

当前仓库提供的是纯前端交互 Demo。设备状态、知识库文档、问答结果和工单数据均为页面内的示例数据；尚未连接实际设备、向量数据库或大模型 API。
