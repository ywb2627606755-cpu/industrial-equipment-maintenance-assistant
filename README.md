# 工业设备智能运维助手

**面向制造车间设备运维场景的 RAG 问答交互 Demo · 个人项目展示**

[在线体验 Demo](https://ywb2627606755-cpu.github.io/industrial-equipment-maintenance-assistant/)

## 项目介绍

受制造车间实习经历启发，本项目围绕设备故障排查与操作规范查询，设计了一个以知识问答为入口的运维助手。希望把分散在设备手册、操作规程和故障案例中的信息，组织成便于现场人员查找、理解和核对的答案。

展示重点是“提出问题 → 查看排查建议 → 核对来源 → 查看设备信息 → 记录处置”的使用流程，同时考虑 4:3 工位屏的阅读空间。界面采用轻量原生 Web 实现，优先保证切换流畅、信息清晰和演示方便。

> 本仓库用于求职与面试展示，仅包含静态前端 Demo 与项目说明。回答、引用、设备状态和工单均为示例数据；在线版本未连接大模型、向量数据库或真实设备。核心实现不在本仓库公开，以下架构说明不代表在线 Demo 已完成后端集成。

## 建议体验顺序

1. **智能问答**：选择快捷问题，查看故障排查或操作规范的示例回答。
2. **引用核对**：点击引用入口，查看来源名称、页码与检索信息的展示方式。
3. **设备档案**：切换左侧导航，查看设备资料、运行指标和维护要点。
4. **知识库**：切换文档类型、输入关键词，筛选示例资料。
5. **处置记录**：回到问答页，体验工单确认，再查看处置记录。

所有交互均在浏览器内运行，无需登录。刷新页面会恢复初始演示状态。

## RAG 架构思路

以下为面向真实系统的设计说明；公开 Demo 仅演示交互，不调用此链路。

```text
知识准备：设备手册 / 操作规程 / 故障案例
               ↓ 文档解析与清洗
             文本分块 + 来源元数据
               ↓ Embedding 向量化
             向量知识库

问答链路：用户问题 + 设备上下文
               ↓ 检索相关片段
             片段内容 + 来源信息 + 问题
               ↓ 大模型生成
             排查建议 / 操作说明 + 引用
```

设计上保留文档名称、章节、页码等元数据，使答案能够回到原始资料核对。对于证据不足的提问，应提示补充设备型号、故障码或现象，避免给出缺乏依据的确定结论。真实系统可考虑在车间内网部署服务，并根据内网条件选择可用的模型接入方式。

| 层次 | 本次展示使用 | 真实系统的架构选型方向 |
| --- | --- | --- |
| Web 前端 | HTML / CSS / JavaScript | 运维问答与引用展示界面 |
| 服务层 | 无，使用页面内示例逻辑 | Python 服务、文档处理与问答接口 |
| 检索层 | 示例文档与检索信息 | Embedding 模型与向量数据库 |
| 生成层 | 预设示例回答 | 大模型 API 或内网可用模型 |
| 发布 | GitHub Pages 静态托管 | 按实际需求部署内网服务 |
